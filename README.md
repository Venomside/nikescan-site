# NikeScan

Public information pages for NikeScan, an independent UK product-comparison and
resale-analytics platform currently in development.

Live at <https://venomside.github.io/nikescan-site/>

- `index.html`
- `affiliate-disclosure.html`
- `privacy.html`
- `404.html`

These pages set no cookies and use no analytics, advertising or tracking, and
they collect no personal details.
